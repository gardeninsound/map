# src/city — the city: map, renderer, movement, neighbors, HUD

Bear Island's own copy of [west-seattle-map](https://github.com/vlandham/west-seattle-map) v0.1.0,
maintained here independently (see the root CLAUDE.md). The map data is generated by
`scripts/city/` (`npm run map:fetch`, `npm run map`, `npm run audit`).

`world/` (tile grid + map data), `engine/` (`CityGame`,
movement, neighbors, input), `render/` (palette, sprites, per-pixel roads, tile art,
landmarks), `ui/` (HUD, dialog box, touch pad, sounds, `ui.css`). Import it via
`src/city/index.ts`. Its unit tests run with the rest. Holding Shift puts the rabbit on a
bicycle at RUN speed (`buildBikeRabbit` in `render/sprites.ts`, `player.riding`; other rabbits
see it through a sixth field on the visitors wire). A plugin can put the player in a `Vehicle`
  (`game.vehicle`: where it can go, its speed, its sprite — the rowboat uses it); Shift does nothing then. What the map draws:
- **two resolutions**: chunks and the map canvas are kept at `RES` (2)× the map's pixels (`render/tileArt.ts`); everything
  is drawn at map size and looks as before, but the trees (`paintFineTrees`, 3 shapes, `buildFineTrees`) and the shoreline
  (`paintFineShore` / `paintFineBeach`: each fine pixel blends the 4 nearest tiles, so water and sand edges curve) use
  half-size pixels, only over bare ground (a 1× chunk is built first, trees left out; anything painted over the ground
  wins). `CityGame` draws through a RES× transform; `ChunkCache.base()` is the 1× chunk (the road audit reads it); the
  newest `KEEP_CHUNKS` fine chunks are kept
- park trails (roadLines with `k`) are thin dirt paths (`TRAIL_R`, `PAL.trail`) down the middle of their walkable
  corridor, which stays lawn
- every public street (no alleys) on its real centreline, at its real width × 2; walkable
  band ≥ 1.5 tiles; ~300 street names (uint16 per tile)
- ~27k houses at their true OSM size/angle (`paintHouses`), nudged back or shrunk where a
  street reaches them; other buildings as tiles
- landmarks (`render/landmarks.ts`): 76 station, Admiral Theatre, Easy Street, the Undersea
  Aviary, the 7-Eleven, Admiral Safeway, Shadowland, West Seattle Library, Dakota Place Park (the old brick
  substation and its plaza), the 1911 Alki Bathing Pavilion (gone since 1955, drawn on its site from the
  written record; the sources are in its comment), Hope Lutheran Church (42nd & Oregon; an interpretation of its
  OSM outline, idea box #44), and the Junction block faces (`render/storefronts.ts`, data in
  `world/storefronts.ts`, shop fronts in `render/facades.ts`); a landmark with a `street`
  side is pulled flush with that street's sidewalk at render time
- detailed places (Hiawatha Playfield, West Seattle High School): lawn, walkable footpaths
  and parking lots (Tile.Parking), pitches/track/courts/pool, buildings from exact
  outlines (`render/detailArt.ts`)
- **sites** — places OSM doesn't have, drawn in by the map build from data (`scripts/city/sites/*.json`, applied by
  `scripts/city/sites.mjs` after the landmarks and before the houses): an ASCII grid of cells anchored by lat/lon
  (`l` lawn, `w` walkable + named, `W` walkable, `n` named), plus a label, paths and detail features in lat/lon. Never
  hand-edit `worldData.json` (the next `npm run map` erases it); `scripts/city/sites.test.mjs` fails if the committed
  map is missing a site. So far: **West Seattle Stadium** (35th Ave SW; OSM only has an unnamed wooded park): lawn
  grounds, the walkable track and football field, grandstands along 35th and a gate path in from the sidewalk
  (features/road line tagged `stadium`)
